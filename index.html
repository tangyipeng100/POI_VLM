RUN THE PUBLIC PIECES / 运行开源部分

Two commands.
Visible outputs.

The release keeps the reusable geometry stage and the model-inference bridge separate. Run the first offline; connect the second to any OpenAI-compatible vision endpoint when you have credentials.

01 / POI GENERATOROFFLINE

Turn a mask into candidates.

Start from the bundled front frame and drivable-area mask. The script cleans the mask, extracts a polygon, classifies edges, applies priority-aware suppression, and draws stable numbers.

cd open_source
python examples/generate_poi_example.py

02 / INFERENCE BRIDGEOPENAI-COMPATIBLE

Send the same view to a VLM.

The bridge packages the composed front/map image, supports Chat Completions or Responses, retries transient failures, and returns only a small action object.

$env:VLM_API_KEY = "your-key"
python inference_bridge.py --image assets/question.png --model your-vision-model
